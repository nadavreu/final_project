│    ┌─────────────────────────────────────────────────────────────────────────┐   │

│    ┌─────────────────────────────────────────────────────────────────────────┐   │

│    │ 9.2 HEART RATE BAND FILTERING                                          │   │

│    ┌─────────────────────────────────────────────────────────────────────────┐   │

│    │    • Find peaks with distance=5, prominence=0.15*max_power             │   │
│    │    • Score peaks based on:                                             │   │
